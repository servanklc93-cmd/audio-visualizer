# Audio Visualizer 🎵

Müziğe göre dans eden gerçek zamanlı ses görselleştirici.

## Özellikler
- 4 farklı mod: BARS, CIRCLE, WAVE, PARTICLES
- 5 renk teması: Gökkuşağı, Ateş, Okyanus, Neon, Altın
- Bass/Mid/Treble göstergesi
- Beat detection efekti
- Tam ekran modu
- Three.js ile 3D görsel (3D SPHERE modu)

## Kullanım
1. `index.html` dosyasını tarayıcıda aç
2. "MÜZİK YÜKLE" butonuna bas
3. Bilgisayarından bir MP3 dosyası seç
4. Mod ve renk teması seç, keyfini çıkar

## Teknolojiler
- HTML5 Canvas API
- Web Audio API
- Three.js (r128)
- Vanilla JavaScript
